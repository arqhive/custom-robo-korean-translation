# 커스텀 로보 (N64) 한글 패치

*Custom Robo* (닌텐도 64, 일본판 `NCXJ`) 비공식 한국어 팬 패치입니다.
일본판(『カスタムロボ』) 원문을 기준으로 번역했습니다.

**제작: arqhive** · **최신 버전: [v1.0f](../../releases/tag/v1.0f)**

- 본편 대사, 선택지, 메뉴, 파츠 설명, 용어집·튜토리얼, 스테이지 설명, 저장 안내, 스태프 크레딧을 한글화했습니다.
- 타이틀 로고와 메뉴·지도·간판·포스터 그림 속 글자를 한글화했습니다.
- 주인공 이름을 한글로 입력할 수 있습니다. 이름 뒤 조사(을/를, 이/가 등)는 이름 끝 글자의 받침에 맞춰 자동으로 바뀝니다.
- 원작에서도 영어인 문구는 영어 그대로 두었습니다.
- 배포본은 원본 롬에 적용하는 **xdelta 패치**입니다. 롬 크기(16MB)는 그대로이며 확장팩은 필요 없습니다.

> 이 저장소에는 **게임 데이터(롬, 추출한 원문 대사, 원본 그래픽, 스크린샷)가 들어 있지 않습니다.**
> 패치를 적용하려면 본인이 소유한 게임에서 직접 덤프한 원본이 필요합니다.

## 사용자용: 패치 적용

### 준비물

- 일본판 롬 파일(z64, 빅 엔디언). 북미판·유럽판은 없는 게임입니다.

| 항목 | 값 |
|---|---|
| 크기 | 16,777,216바이트 |
| MD5 | `a06d2e83cf2628915e8847f609474661` |
| SHA-256 | `9b66c00a983ceccccf17727731173d7c7eeef9f7c13faf44ae89e5d2b9f656c1` |

`.v64`·`.n64`처럼 바이트 순서가 다른 파일은 먼저 z64로 바꿔야 합니다.

- xdelta 패치를 적용하는 프로그램(Delta Patcher, xdelta UI 등).

### 적용 방법

1. [릴리즈 페이지](../../releases/latest)에서 `NCXJ_KPatch_v<버전>.xdelta`를 받습니다.
2. 패치 프로그램에서 원본 롬과 xdelta 파일을 고르고 적용합니다.
3. 만들어진 롬을 실행합니다. 결과 롬의 해시는 함께 올린 `README_KO.txt`에 있습니다.

### 실행 환경

- **확인함**: RMG(Rosalie's Mupen GUI), Wii U 버추얼 콘솔(UWUVCI 주입, 베이스 Paper Mario JP).

## 개발자용

- 번역문: [`work/translation/`](work/translation)에 ID별 한국어 번역문만 들어 있습니다. `$R`은 줄바꿈, `$P`는 쪽 넘김, `$W`는 입력 대기, `$A00`은 주인공 이름 자리라 그대로 둡니다. `{을/를}`·`{이/가}`·`{은/는}`·`{과/와}`·`{아/야}`·`{이}`·`{으}`·`{에/예}`는 이름 뒤 조사 표기입니다.
- 도구: [`tools/`](tools)에 추출·글꼴·빌드·검증·배포 도구 소스가 있습니다(Python 3.13, NumPy, Pillow, keystone-engine, unicorn).
- 일본어 원문 추출본, 그림 작업 파일, 작업 상태 기록은 게임 데이터이거나 작업용이라 넣지 않았습니다. 그래서 이 저장소만으로는 바로 빌드되지 않고, 원본 롬에서 추출부터 다시 해야 합니다.
