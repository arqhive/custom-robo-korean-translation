「カスタムロボ」(N64, 일본판) 비공식 한국어 팬 패치입니다.
본편 대사, 메뉴, 파츠 설명, 용어집·튜토리얼, 스테이지 설명, 저장 안내, 스태프 크레딧,
타이틀 로고와 메뉴·지도·간판 그림 속 글자를 한글로 바꿉니다.


[준비물]

- 일본판 「カスタムロボ」 롬 파일(z64, 빅 엔디언).
  .v64·.n64처럼 바이트 순서가 다른 파일은 먼저 z64로 바꿔야 합니다.
- xdelta 패치를 적용하는 프로그램(Delta Patcher, xdelta UI 등).


[적용 방법]

1. 패치 프로그램에서 원본 롬과 NCXJ_KPatch_{VERSION}.xdelta 를 고릅니다.
2. 적용하면 한글판 롬이 만들어집니다.
3. 만들어진 롬의 해시가 아래 「패치 후」와 같은지 확인합니다.


[해시]

  패치 전(원본 롬)
    크기    16,777,216 바이트
    MD5     a06d2e83cf2628915e8847f609474661
    SHA-256 9b66c00a983ceccccf17727731173d7c7eeef9f7c13faf44ae89e5d2b9f656c1

  패치 후({VERSION})
    크기    16,777,216 바이트
    MD5     {RESULT_MD5}
    SHA-256 {RESULT_SHA256}


[실행 환경]

- 확인함: RMG(Rosalie's Mupen GUI), Wii U 버추얼 콘솔(UWUVCI 주입, 베이스 Paper Mario JP).


[참고]

- 주인공 이름은 한글로 입력할 수 있습니다. 이름 입력 첫 페이지에서 자음·모음을 차례로 고르면
  글자가 조합됩니다(최대 6글자). R·L 버튼으로 히라가나·영문 페이지로 바꿀 수 있습니다.
- 원래 영어로 나오는 글자는 영어로 두었습니다.
